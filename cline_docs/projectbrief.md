# Project Brief — Lyrion Yandex Bridge

## Что это
Устройства «музыка» из Умного дома Яндекса (УДЯ) и голосовой навык «Раз Два»
для плееров Lyrion Music Server (LMS).

## Состав системы (3 части)
1. **sa_client** (этот проект, java) — клиент: выполняет запросы Яндекса рядом с LMS.
   Провайдер УДЯ (`/v1.0/...`), навык «Раз Два» (`/alice/`), команды Tasker/пульта (`/cmd`),
   Spotify (`/spotify`), TTS и звуки, веб-настройки на порту 8888, облачный транспорт (`CloudClient`).
2. **sa_server** (отдельный проект `/home/konstantin/IdeaProjects/sa_server`, Spring, Zeabur) —
   «глупый релей»: принимает HTTPS от Яндекса, пересылает клиенту по WebSocket, ответ возвращает как есть.
3. **Плагин LMS** (`lms-plugin/`, perl) — запускает jar клиента как фоновый процесс LMS:
   автостарт, автоперезапуск, страница настроек в вебе LMS, сводка «Client status».

## Результат для пользователя
Установка плагина из репозитория `https://raw.githubusercontent.com/knovash/lyrion-yandex-bridge/main/repo.xml`,
авторизация в Яндексе (OAuth) — колонки LMS появляются в УДЯ как устройства «музыка»,
управление голосом через Алису (громкость, каналы/плейлисты, группы, «что играет»).
